# 🛒 Retail FreshMart

Retail FreshMart is a web-based retail management system designed to streamline store operations such as sales tracking, inventory monitoring, and performance analytics.

The system now includes a secure user authentication module with Login, Signup, and Account Creation features, providing a personalized experience for users.

## 🚀 Features

### 🔐 Authentication System

* User Registration (Create Account)
* Secure Login Functionality.
* User Logout Feature.
* Form Validation for Authentication.
* Personalized User Access.

### 📊 Dashboard

* Key Performance Indicators (Sales, Profit, Stock Alerts)
* Interactive Dashboard Interface.
* Real-time Business Insights.

### 📦 Inventory Management

* Product Inventory Tracking.
* Low Stock Monitoring.
* Stock Status Management.

### 📈 Sales Analytics

* Sales Performance Analysis.
* Category-wise Sales Reports.
* Data Visualization with Charts.

### 🔍 Search & Filter

* Quick Product Search.
* Data Filtering for Better Insights.
* Organized Information Display.

## 🎯 Objective

The goal of this project is to simulate a real-world retail management system that enables store managers to monitor sales performance, manage inventory efficiently, authenticate users securely, and make data-driven business decisions.
